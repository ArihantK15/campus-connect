Campus Connect

RUN LOCALLY
1. Install dependencies from the project folder:
       pip install -r requirements.txt
2. Run `python app.py` from the project folder, or double-click Start.command.
   The local address is printed in the terminal.

USING THE APP
- There is no sign-in. Pick a sample user from the "Viewing as" menu at the
  top right. Choose "Browse as guest" to look around without a user.
- Events, registrations, saved events, and communities are stored by the
  Campus Connect server (SQLite) and shown for whichever user is chosen.

This application is not affiliated with a real university. No payments are
collected. See the project README for the API and deployment notes.
